# 命令速查表

先按共同部署指南获得权限并配置；以下从 Project3 根目录执行。

| 目的 | 命令 | 执行位置 |
|---|---|---|
| 环境探测 | `bash -l scripts/detect_env.sh` | 集群登录节点 |
| 编译 | `bash -l scripts/build.sh` | 学校允许的编译节点 |
| 代码行号 | `nl -ba src/parallel.cpp` | 集群登录节点 |
| 生成双节点检查 | `python3 scripts/make_jobs.py --preset smoke --iters 100 --repeats 3` | 集群登录节点 |
| 生成正确性作业 | `python3 scripts/make_jobs.py --preset verify` | 集群登录节点 |
| 查看本人作业 | `qstat -u "$USER"` | 集群登录节点 |
| 查看单作业 | `qstat -f "$JOB_ID"` | 集群登录节点 |
| 汇总官方数据 | `python3 scripts/analyze.py --official-only` | 集群登录节点或本机 |
| 图表 | `python scripts/analyze.py --official-only --plots` | 已装 matplotlib 的本机 venv |
| 源码包 | `python3 scripts/package.py --kind source` | 本机/集群 |
| 完整预审包 | `python3 scripts/package.py --kind full` | 汇总目录 |
| 最终包 | `python3 scripts/package.py --kind full --final` | 完成报告后的汇总目录 |

### 生成正式矩阵示例

这些命令只生成脚本，不自动执行。示例核数、轮数和规模需预跑确认。

```bash
python3 scripts/make_jobs.py --preset strong --n 512 --iters 10000 --repeats 5 --cpus-per-node 8 --single-node-cores 1,2,4,8 --nodes-list 1,2
python3 scripts/make_jobs.py --preset strong --n 1024 --iters 10000 --repeats 5 --cpus-per-node 8 --single-node-cores 1,2,4,8 --nodes-list 1,2
python3 scripts/make_jobs.py --preset weak --n 256 --iters 10000 --repeats 5 --cpus-per-node 8 --single-node-cores 1,2,4,8 --nodes-list 1,2
python3 scripts/make_jobs.py --preset mix --n 1024 --iters 10000 --repeats 5 --cpus-per-node 8 --nodes-list 1,2 --mix-threads 1,2,4,8
python3 scripts/make_jobs.py --preset comm --n 1024 --iters 10000 --repeats 5 --cpus-per-node 8 --nodes-list 1,2 --mix-threads 2
python3 scripts/make_jobs.py --preset check --n 64 --iters 200000 --repeats 5 --cpus-per-node 8 --nodes-list 1
```

### 提交单个已经审核的脚本

```bash
JOB_DIR=$(ls -td jobs/generated/verify-* | head -n 1)
cat "$JOB_DIR/p3-verify-1.pbs"
bash -n "$JOB_DIR/p3-verify-1.pbs"
JOB_ID=$(qsub "$JOB_DIR/p3-verify-1.pbs")
qstat -f "$JOB_ID"
```

替换 preset/文件名时以 manifest.json 和生成器打印路径为准；不要通过手改脚本让申请资源与程序线程数矛盾。
